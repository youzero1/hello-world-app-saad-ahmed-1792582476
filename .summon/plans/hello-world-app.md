# Hello World app

A small single-purpose app built around the classic "Hello, World!" message, with three different takes to choose from. Since the project is currently empty, every option includes the full starter setup.

## Common steps

1. **Create the project configuration files**
   - Files: `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`
   - `package.json` declares React, TanStack Router (with the router plugin), Tailwind CSS v4 (with its Vite plugin), Vite, and TypeScript, plus dev/build scripts.
   - `vite.config.ts` registers the TanStack Router plugin and the Tailwind CSS v4 plugin, and sets the `@/` path alias to `src/`.
   - `tsconfig.json` enables strict TypeScript and the `@/` alias.
   - `index.html` is the Vite entry page mounting a root element and loading `src/main.tsx`.
   - Expected outcome: the project installs and starts as a standard Vite app.

2. **Create the global stylesheet**
   - File: `src/styles/global.css`
   - Starts with exactly `@import "tailwindcss";` and sets a pleasant page background and default text color for the app.
   - Expected outcome: Tailwind utilities work throughout the app and the page has a polished base look.

3. **Create the app entry point**
   - File: `src/main.tsx`
   - Imports `src/styles/global.css` once, creates the TanStack Router instance from the generated route tree, and renders the app into the root element.
   - Expected outcome: the app boots and routing is wired up.

4. **Create the root layout route**
   - File: `src/routes/__root.tsx`
   - Renders the app shell: a full-screen container that centers its content, with an `Outlet` for child routes.
   - Expected outcome: every page renders inside a centered, full-height layout.

5. **Verify the build**
   - Run the TypeScript check and production build to confirm everything compiles and the route tree generates correctly (`src/routeTree.gen.ts` is generated by the router plugin, never hand-written).
   - Expected outcome: no type or build errors; the app renders the page in the preview.

## Option: Simple static page

1. **Create the Hello World home page**
   - File: `src/routes/index.tsx`
   - The `/` route shows a large "Hello, World!" heading with a short welcoming subline, styled with Tailwind (bold typography, subtle accent color, soft spacing) so it looks intentional rather than plain.
   - Expected outcome: visiting the app shows an attractive Hello, World! screen.

## Option: Personalized greeting

1. **Create a greeting form component**
   - File: `src/components/GreetingForm.tsx`
   - A text input asking for the visitor's name with a button to submit it; on submit it updates the greeting on screen.
   - Expected outcome: typing a name and pressing the button updates the page.

2. **Create the personalized home page**
   - File: `src/routes/index.tsx`
   - The `/` route shows "Hello, World!" by default, and swaps in "Hello, <name>!" once the visitor enters their name, with a smooth, friendly layout built around the form component.
   - Expected outcome: the page greets each visitor personally.

## Option: Multi-language greetings

1. **Create the greetings data**
   - File: `src/lib/greetings.ts`
   - A typed list of greetings — "Hello, World!" rendered in several languages (English, Spanish, French, German, Japanese, Arabic, and more), each with its language name.
   - Expected outcome: a reusable data source for the greetings.

2. **Create the greeting switcher component**
   - File: `src/components/GreetingSwitcher.tsx`
   - A row of language buttons; clicking one swaps the big greeting on screen, with the active language highlighted.
   - Expected outcome: visitors can flip between languages instantly.

3. **Create the multi-language home page**
   - File: `src/routes/index.tsx`
   - The `/` route shows the current greeting large and centered with the switcher below it, styled for a clean showcase feel.
   - Expected outcome: a playful page for browsing "Hello, World!" around the globe.
